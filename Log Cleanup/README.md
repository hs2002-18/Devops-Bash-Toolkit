# 🧹 Log Cleanup Automation Script

## 📌 Problem

Log files generated by applications can grow rapidly over time, consuming disk space and potentially impacting system performance. Manually cleaning up old logs is inefficient and error-prone.

---

## 💡 Solution

This project provides a Bash script that automates log file cleanup by identifying and removing logs older than a specified number of days. It also maintains a record of all actions performed, ensuring transparency and traceability.

The script performs the following:

* Checks if the target log directory exists
* Identifies `.log` files older than a defined threshold
* Logs all actions with timestamps
* Deletes outdated log files safely
* Handles cases where no files are found

---

## 🛠️ Tech Used

* Bash (Scripting)
* Linux Commands (`find`, `date`, `tee`)
* File System Operations

---

## 📚 What I Learned

* Automating system maintenance tasks using Bash
* Working with file search and filtering using `find`
* Implementing safe deletion practices
* Adding structured logging with timestamps
* Handling edge cases in scripts (missing directory, no files found)

---

## ▶️ How to Run

1. Make it executable:

   ```bash
   chmod +x script.sh
   ```

3. Run the script:

   ```bash
   ./script.sh
   ```
